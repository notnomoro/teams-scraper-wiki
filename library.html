API de Python

El paquete público es teams_scraper. La versión de esta guía es 1.0.0. Python 3.11 o más nuevo. La dependencia es Selenium 4.25 o más nuevo.

from teams_scraper import connect, list_tasks, run

run("upcoming", limit=1)
with connect() as store:
    for task in store.list_tasks():
        print(task["titulo"])

run lanza TeamsScraperError. La terminal imprime el código y sale con 1. Tu programa lee error.code. La causa original queda pegada cuando la hay. Los códigos están en Errores.

Nombres públicos

NombreQué es
runUna lectura. Si no pasas almacén, abre SQLite.
connectAbre SqliteAlmacen, o te devuelve el almacén que pasaste.
list_tasksTareas guardadas. tab puede ser Upcoming, Past due, Completed o Grades.
list_filesArchivos guardados.
AlmacenEl contrato. Lo heredas y lo pasas a run(store=...).
SqliteAlmacenEl almacén que viene hecho. Escribe teams.db.
MemoryAlmacenEl mismo contrato en memoria, para una prueba que no debe abrir SQLite.
TeamsScraperErrorFallo con code estable y mensaje en el idioma activo.

run

run(
    mode="upcoming",
    *,
    store=None,
    browser=None,
    subjects=None,
    parts=None,
    limit=0,
    no_detail=False,
    keep_open=False,
    chat="",
    download=None,
    interactive=False,
    language=None,
)
ArgumentoQué hace
modeupcoming, past-due, completed, activity, channels, chats, downloads, sync, open o all.
storeUn Almacen. Si es None, se abre SQLite y se cierra al terminar.
browserId de la config o ruta del ejecutable, para esta llamada.
subjectsLista de atajos o nombres. Hace falta en channels y all si la config no tiene clases.
partsPartes de canal. Si no las pasas, posts y shared.
limitCuántas tareas abrir. 0 son todas.
no_detailNo abre cada tarjeta.
keep_openNo cierra la ventana al terminar.
chatNombre permitido, o all. Obligatorio en chats.
downloadNone usa la config. False no descarga en esta llamada.
interactiveFalse por defecto. Si Teams pide sesión, lanza auth.login_required. La terminal pone esto en verdadero cuando hay alguien al teclado, y entonces espera un Enter.
languageen o es para esta llamada.

Carpeta de datos

run no recibe la carpeta. connect(data_dir=...) la fija, o llamas a teams_scraper.paths.set_data_dir antes. La variable TEAMS_SCRAPER_HOME hace lo mismo. Si no hay ninguna, la carpeta es datos/ en el directorio actual.

run("upcoming", limit=1, store=my_store)

El contrato de my_store está en Almacén. Las tablas de SQLite están en Datos.
