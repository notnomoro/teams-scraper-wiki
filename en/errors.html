Errors

A failed run raises TeamsScraperError. The code is stable English. The sentence follows the language. The terminal prints both and exits 1.

[ERROR] config.missing: There is no config yet. Run: teams-scraper init

With --lang es the code stays config.missing and the sentence changes. From Python, read error.code. The original failure is attached as the cause when there is one.

A bad command or a bad flag exits 2. That path is the argument parser, not one of these codes.

CodeWhen it happensWhat to run
config.missingThere is no config yet.teams-scraper init
config.invalidThe config is not valid, or it has no browser. A bad --part uses this code too.teams-scraper init
browser.not_foundThe executable is missing, or no browser is configured.teams-scraper config
browser.profile_lockedThat browser already has this profile open, and the lock cannot be removed.Close that window, then run the same command.
browser.start_failedThe window could not be prepared.Run the same command again.
browser.closedThe browser window was closed.Run the same command again.
network.unreachableteams.microsoft.com on port 443 did not answer.Check the network.
auth.login_requiredTeams is asking for a sign-in. A terminal waits and asks you to press Enter. Code raises this instead of waiting.teams-scraper open
subjects.missingThis mode needs a class.teams-scraper init
chats.missingchats was started without a chat, or the Chat button did not appear.teams-scraper config, or pass --chat.
chats.not_allowedThat chat is not on the allowed list.teams-scraper config
teams.timeoutTeams, a tab, or a file list did not finish loading.Run the same command again.
teams.assignments_unavailableAssignments did not open.Run the same command again.
teams.card_missingThat card is not in the list.
teams.card_mismatchThe opened assignment does not match the card, so nothing was saved.

teams.class_missingThat class is not in the Teams list.Check name in the config. It has to match Teams.
teams.channel_missingThat channel is not in the list.
teams.chat_unavailableChat did not open, or the conversation did not stay selected.
teams.chat_list_missingThe chat list did not appear.
teams.chat_list_emptyThe chat list did not show a conversation.
teams.read_failedThis step could not finish. The sentence names the step.
storage.missing_idA task needs an id before it can be stored.
storage.bad_idThat id cannot be a folder name, so the catalog was not written.
storage.failedThe store raised. The sentence includes the detail.
