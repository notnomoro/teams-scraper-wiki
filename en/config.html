Commands / config
EnglishEspañol

config

teams-scraper config changes one field in config.json. The aliases are configurar and editar.

The menu edits one part at a time: language, classes, chats, browser, folder, downloads, or the previous config. You can also edit the JSON yourself.

If the file is missing, a read stops with config.missing. If it is broken, or it has no browser, the code is config.invalid. Both tell you to run init.

The names below are the ones the example uses. They are not a real class.

{
  "language": "en",
  "browser": {
    "id": "chrome",
    "label": "Google Chrome",
    "engine": "chromium",
    "executable": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
    "profile": "perfil"
  },
  "subjects": [
    {
      "shortcut": "hist",
      "name": "History 101",
      "teacher": "A. Example"
    }
  ],
  "chats": ["Study group"],
  "download_files": true
}

Language

FieldDefaultWhat it does
languageenLanguage of the messages this tool prints. en or es. Teams itself can use another language. --lang overrides this for one run.

Browser

FieldDefaultWhat it does
browser.idchrome, edge, brave, opera, firefox, librewolf, zen, or the executable name.
browser.labelName printed in the run header.
browser.enginechromium or firefox. There is no third engine.
browser.executableFull path to the .exe. If the file is missing, browser.not_found.
browser.profileperfilProfile folder inside the data directory. It is created for this tool.

A bundled LibreWolf that lives under the data folder keeps librewolf/Profiles/Default when that profile is already there. If that profile is open and the lock cannot be removed, the run stops with browser.profile_locked.

Classes

FieldDefaultWhat it does
subjects[]Classes the tool may open for channels.
subjects[].shortcutShort name you pass with -s. Example: hist.
subjects[].nameClass name as it appears in Teams.
subjects[].teacheremptyStored next to the class. Leave it empty and the task row uses desconocido.

Teams sometimes replaces ñ with a broken character. If that broken form matches a teacher saved here, the stored name is the one that is kept.

Chats and downloads

FieldDefaultWhat it does
chats[]Conversations this tool may open.
download_filestrueSave files under descargas/. false stores the names and skips the download.

Data folder

The folder is not a field inside the JSON. It is where the JSON lives. The default is datos/ in the current directory. --data DIR points one run at another folder. TEAMS_SCRAPER_HOME does the same when you launch the tool from another program.
