chats

Messages in the conversations on the allowed list. This command is not part of all.

teams-scraper chats --chat "Study group"
teams-scraper chats --chat all

It needs --chat NAME or --chat all. todos is the same as all. Without that, or if the Chat button did not appear, the code is chats.missing.

A name that is not in chats in the config stops with chats.not_allowed. Add it with config. Anything left off the list is never opened.

What it reads

It opens the conversation, prints the visible messages, and, when downloads are on, saves the files on screen. It does not walk a chat you left out. If the chat does not stay selected, the code is teams.chat_unavailable. If the list does not appear, teams.chat_list_missing. If it shows no conversation, teams.chat_list_empty.
