When it fails

The code is enough to see what happened. Do not paste cookies, session files, or other people's names into an issue.

There is no config

The line is config.missing. Run teams-scraper init. The program does not invent a class or a browser.

The sentence is English and you wanted Spanish

The code stays in English on purpose. --lang es changes the sentence for that run. language in the config changes it for the next ones.

The browser does not start

  • browser.not_found: the .exe path is gone. teams-scraper config and pick another, or paste the path.
  • browser.profile_locked: close the window that already uses this profile and run the same command.
  • browser.start_failed or browser.closed: run it again. If you closed the window yourself, it is browser.closed.
  • Extensions, blockers, and privacy shields break Teams. Turn them off in the profile this tool opens, then reload.

It asks you to sign in

In the terminal, sign in in the window and press Enter. From Python, with interactive=False, you get auth.login_required. teams-scraper open leaves the window open so you can sign in.

That profile starts without your everyday session. The first time asking for the account is expected.

There is no network

network.unreachable means teams.microsoft.com on port 443 did not answer. The run does not continue from a half-loaded page.

The class is missing

teams.class_missing: name has to be the name Teams shows. subjects.missing: channels and all need a class. Check it with init.

Teams sometimes breaks ñ. If you saved the teacher in the config, that name is used when the broken form matches.

Assignments does not load

teams.timeout or teams.assignments_unavailable: run the same command. Assignments are drawn inside an iframe. A page that did not load is not stored as an empty list. What is already in the database stays.

teams.card_mismatch does not save that card, because the opened title is not the one on the list. teams.sharepoint_unavailable does not save that file pass.

Chat does not open

It has to be on the chats list. Otherwise chats.not_allowed. If you forgot --chat, chats.missing. all does not read chats. Run chats on its own.

The exit status is 2

The command or the flag does not exist. Help suggests a close match. teams-scraper --help lists the names. Aliases are in Reference.

You want to report it

Include the browser, the mode, the version, and the code. Check that it still happens on the latest release. The repository templates ask for the same thing.
