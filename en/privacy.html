Privacy

Teams Scraper has no account of its own, no server, and no analytics. It reads Teams in a browser you choose and writes the result on your machine.

What is stored

Everything stays in the data folder, datos/ unless you picked another one.

PathWhat it holds
config.jsonLanguage, browser path, class names, teacher names, and the chats you allowed.
perfil/The browser profile for this tool, including the Microsoft sign-in.
teams.dbAssignments, files, grades, posts, and notifications.
catalogo/, *.jsonCopies of those lists.
descargas/Files the run saved.

config.prev.json keeps the previous config so revert can put it back.

What it opens

It opens https://teams.cloud.microsoft with Selenium. It reads the assignments, channels, grades, and chats that the signed-in account can already see. Chats that are not on the allowed list are not opened.

The profile in the data folder is separate from the profile you use every day.

What it does not do

It does not submit an assignment, post a message, or send the rows to the author of this project. A failed page is not treated as an empty class: the run stops with a code, and a stored value is left in place when the new read is empty.

What to keep private

Do not commit the data folder. Do not paste cookies, session files, or other people's names into an issue. The error code is enough. The templates say the same thing.
