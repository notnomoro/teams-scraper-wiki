Changelog

1.0.0 — 26 November 2026

First public release. A Selenium reader for students on academic Teams. It does not submit anything.

  • Command teams-scraper: init, then upcoming, past-due, completed, activity, channels, chats, sync, open, and all.
  • Setup asks for the language, the browser, and the data folder, opens Teams, and lets you check the classes to read. Each checked class then asks for the teacher and a shortcut.
  • Browsers on the Chromium engine (Chrome, Edge, Brave, Opera) and the Firefox engine (Firefox, LibreWolf, Zen), or any executable path.
  • Store contract in Almacen. SQLite is the one that ships. Another project can pass its own object to run(store=...).
  • Errors with a stable code. The sentence follows --lang. The code does not.
  • English by default, Spanish with --lang es or language in the config.
  • The guide lives on this site. The program repository no longer keeps a copy under docs/.

The tag is v1.0.0.
