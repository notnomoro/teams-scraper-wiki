Command reference

Each command reads one thing. all joins several. Chats are not part of all.

CommandWhat it readsBrowser
upcomingAssignments that are not due yet.Yes
past-dueAssignments past the due date.Yes
completedAssignments already turned in.Yes
activityNotifications since the last read.Yes
channelsPosts, shared files, channels, and grades.Yes
chatsMessages in the chats you allowed.Yes
downloadsWhere files already saved came from.No
syncCopies the catalog into the database and rewrites activity.json when there are notices.No
openOpens Teams and waits. Nothing is read.Yes
allActivity, upcoming, past due, completed, and channels.Yes
initLanguage, browser, classes, chats, folder, and downloads.Yes, to check classes
configChange one saved field.No
revertPut back the previous config.No

Examples

teams-scraper upcoming
teams-scraper channels -s hist -p posts,grades
teams-scraper chats --chat all
teams-scraper upcoming --lang es --limit 1
teams-scraper config
teams-scraper revert

channels without a class stops with subjects.missing. chats without --chat stops with chats.missing. Flags are in Options.

What a run prints

The header names the mode, the browser, and the clock. Each step is marked. The end is a summary: state, mode, items, and duration.

EnglishWith --lang esMeaning
STEPPASOA step in progress.
OKOKThat step finished.
INFOINFOA note, such as a saved card that was skipped.
NOTEAVISOSomething that limits the run.
COMPLETECOMPLETAThe steps finished.
PARTIALPARCIALA step was skipped or limited.
FAILEDFALLIDAThe run stopped. The note is code: sentence.

--limit reads that many assignments and leaves the previous JSON copy in place. A card that is already complete is skipped, with the exceptions of each list. A partial read does not replace a stored value with an empty one.

A bad flag or an unknown command exits with status 2 and suggests a close match. A failed read exits with status 1 and prints code: sentence.
