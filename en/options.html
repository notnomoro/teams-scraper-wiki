Options

The same flags apply to read commands. init, config, and revert ask in the terminal instead of using these flags.

OptionWhat it does
-s, --subject NAMEShortcut or class name. Repeat the flag for more than one. It picks classes for channels and all.
-p, --part LISTChannel parts, separated by commas: posts, shared, assignments, channels, grades.
--chat NAMEA name from the allowed list, or all.
--limit NHow many assignments to open. 0 means all of them.
--no-detailList the cards and do not open each assignment.
--no-downloadDo not download files on this run.
--keep-openLeave the window open when the run ends. open leaves it open anyway.
--browser ID|PATHBrowser id from the config, or a path to an executable, for this run.
--lang en|esLanguage for this run. The error code stays in English.
--data DIRFolder for the config, the profile, and the database, for this run.
--modeThe same name as the command, if you pass it as a flag.
-h, --helpShow the help and exit 0. ayuda does the same.
--versionPrint teams-scraper 1.0.0 and exit.

Exit status

StatusWhen
0The run finished, even when the summary is partial.
1TeamsScraperError. The line is code: sentence.
2A command or flag the argument parser rejected. It suggests a close match.
