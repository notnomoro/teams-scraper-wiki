all

One pass over activity, upcoming, past due, completed, and channels. The alias is todo. Chats are not included.

teams-scraper all
teams-scraper all -s hist -p posts,shared,grades

The order is fixed: Activity, then Assignments (upcoming, past-due, completed), then channels. At least one class is required, because the channel step needs it. Without one, subjects.missing.

If you omit -p, channels read posts and shared. -s picks the classes for that step. The three assignment lists are read in full, with the same skip rules as each command on its own.

If one list is limited, the summary of the whole run is PARTIAL. If a step raises a code, the run closes as FAILED and what was already stored stays.
