Store

The reader talks to an Almacen. It does not open sqlite3 itself. SqliteAlmacen writes teams.db. MemoryAlmacen is the same contract in memory.

from teams_scraper import Almacen, run

class JsonStore(Almacen):
    def __init__(self):
        self.tasks = []

    def save_task(self, task, tab, run_id=None, clear_reread=False):
        self.tasks.append(
            {
                "tab": tab,
                "id": task.get("id_en_html"),
                "title": task.get("titulo"),
            }
        )

store = JsonStore()
run("upcoming", limit=1, store=store)

Almacen already implements the other methods as empty results. Override the ones you want to keep. save_task is the one that raises if you forget it.

A task needs id_en_html or id_tarea. Without an id the code is storage.missing_id and nothing is written. An empty field on a later read does not replace a value that is already stored. A shorter prefix of a stored sentence does not replace it either.

Methods

MethodWhat the reader expects
start_run(mode)Open a run. Return an id.
finish_run(run_id, result, processed, notes="")Close it. result is completa, parcial, or fallida.
save_task(task, tab, run_id=None, clear_reread=False)Store one assignment. tab is Upcoming, Past due, Completed, or Grades.
task_needs_reread(task_id)True when Activity asked for this card again.
task_snapshot(task_id)The stored due date and list status, or None.
list_tasks(tab=None)Assignments. tab filters one list.
list_files()Files already stored.
save_notifications(items, run_id=None)Activity rows. Return how many were new.
apply_notification_actions(items, run_id=None)Mark cards that Activity wants read again. Returns channel notices, rereads, and new tasks without detail.
save_channel_posts(posts, run_id=None)Channel posts.
save_channel_folder(record, run_id=None)One shared folder.
save_team_channel(record, run_id=None)One channel name.
save_channel_file(record, run_id=None)One shared file.
channel_file_downloaded(subject, channel, folder, name)The stored file, or None.
save_grade(record, run_id=None)One grade row.
sync_catalog()Copies catalogo/ into the database when those files exist. Every run calls it before reading.
stats()Counts for the closing line: tasks, lists, files, notices, folders, and rereads.
close()Release the connection. connect() works with with.
