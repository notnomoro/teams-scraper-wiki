Architecture

The command parses flags, run opens Teams, and a store object receives the rows.

teams-scraper
    cli.py            flags, init, config, revert
    runner.py         one mode, then the summary
    browser.py        Chromium or Firefox, profile in the data folder
    lists.py          Upcoming, Past due, Completed
    detail.py         one assignment card
    channels.py       posts, shared files, grades
    chats.py          allowed chats only
    activity.py       the Activity list
    storage/          Almacen, SqliteAlmacen, MemoryAlmacen
    locales/          en.json, es.json
    errors.py         TeamsScraperError.code
init→ config.json→ CLI→ Chromium or Firefox→ Teams, read only
CLI→ Almacen Another program→ TeamsScraperError.code Another program→ Almacen

Two engines

Chrome, Edge, Brave, and Opera are Chromium plus the path to the executable. Firefox, LibreWolf, and Zen are Firefox plus that path. A new browser is another path, not a third engine. init lists the ones it finds and accepts a pasted path.

The profile is perfil inside the data folder, unless a bundled LibreWolf already has librewolf/Profiles/Default.

The store

runner calls start_run, the save methods, list_tasks, and finish_run on the object you passed. The method list is in Store.

Language and errors

Strings live in locales/en.json and locales/es.json. A new language is another file in that folder. TeamsScraperError.code stays in English. The sentence follows --lang or language in the config. A caller that imports the package gets the exception, with the original cause attached.

Where Teams is awkward

  • Assignments are drawn inside an iframe. That read enters the frame before it looks for cards.
  • Teams sometimes replaces ñ with a replacement character. If the broken form matches a teacher saved in the config, the saved name is used.
  • A later read that comes back empty, or shorter than what is already stored, leaves the stored value in place.
