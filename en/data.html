Data

SqliteAlmacen.list_tasks() returns rows from tareas. The names are the column names. list_files() reads archivos.

A SQLite error is storage.failed. The sentence includes the database message. The cause stays on the exception. An id that cannot be a folder name is storage.bad_id and that catalog piece is not written.

What list_tasks returns

id_origen, titulo, materia, docente, pestana_vista, fecha_entrega_texto, estado_lista, instrucciones, detalle_completo, requiere_relectura. The row can also carry the rest of the table columns.

Tables in teams.db

TableWhat it keeps
ejecucionesEach run: modo, resultado (en_curso, then completa, parcial, or fallida), tareas_procesadas, notas, start, and end.
tareasAssignments. The key is id_origen.
archivos, tarea_archivosFiles and which assignment they belong to. rol stays no_confirmado until a read sets it.
historial_cambiosA stored field that changed. An empty read does not add a row. The fields compared on a task are title, class, tab, date, statuses, points, and instructions.
notificacionesActivity.
avisos_canalChannel notices seen from Activity.
archivos_canal, carpetas_canal, canales_equipoShared files, folders, and channel names.

Task columns

id_origen, titulo, materia, docente, pestana_vista, grupo_fecha, fecha_entrega_texto, etiqueta, puntos_posibles, estado_lista, estado_entrega, permite_varios_envios, instrucciones, metadatos_json, detalle_completo, requiere_relectura, primera_vez_vista_en, ultima_vez_vista_en, ultima_ejecucion_id, calificacion_texto, comentario.

docente is desconocido when the config has no teacher for that class. calificacion_texto and comentario are added when needed. The grade text is filled when grades is read.
