EnglishEspañol

First run

teams-scraper init writes config.json. Without that file, a read stops with config.missing.

teams-scraper init
teams-scraper upcoming --limit 1

What it asks

  1. Language of the messages. English by default. Spanish with es.
  2. Browser. It lists the ones it finds, including Chrome, or accepts a pasted path.
  3. Data folder. Enter keeps datos/ in the current directory.
  4. It opens Teams. Sign in in that window if it asks, then press Enter.
  5. Classes, with [x] and [ ]. Each checked class asks for the teacher and a shortcut, such as hist.
  6. Allowed chats. Anything left off the list is never opened.
  7. Whether to download files. The default is yes.

Run init again to change one part. teams-scraper config edits the same file. The fields are in Configuration.

After init

The program suggests teams-scraper upcoming, teams-scraper activity, and, if you checked a class, teams-scraper channels -s with that shortcut.

The first read

upcoming --limit 1 opens one assignment and leaves the rest. The result is PARTIAL because the list was not read in full. With --lang es the terminal marks are PASO, OK, INFO, AVISO, COMPLETA, PARCIAL, and FALLIDA.

The aliases of this command are inicio and iniciar.
