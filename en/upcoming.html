upcoming

Assignments that are not due yet. It opens each card unless you limit the run.

teams-scraper upcoming
teams-scraper upcoming --limit 1
teams-scraper upcoming --no-detail

What it stores

Each card goes to the store with the tab Upcoming. When the read opens the assignment, it also stores instructions, points, files, and metadata. A full read writes upcoming.json. With --limit or --no-detail that copy stays, and the summary is PARTIAL.

Cards already stored

A card already stored complete, with files, is skipped. A card stored complete with no files is opened again to recheck them. A card Activity asked to reread is opened again.

-s does not filter this list. The list is the one Teams shows the account. The teacher is filled in when the class name matches the config.

If it stops

config.missing when there is no config. teams.assignments_unavailable when Assignments did not open. teams.card_mismatch when the opened assignment does not match the card: that read is not saved. Assignments are drawn inside an iframe. The read enters the frame before it looks for cards.
