Python API

The public package is teams_scraper. This guide is for 1.0.0. Python 3.11 or newer. The dependency is Selenium 4.25 or newer.

from teams_scraper import connect, list_tasks, run

run("upcoming", limit=1)
with connect() as store:
    for task in store.list_tasks():
        print(task["titulo"])

run raises TeamsScraperError. The terminal prints the code and exits 1. Your program reads error.code. The original cause is attached when there is one. The codes are in Errors.

Public names

NameWhat it is
runOne read. If you omit the store, it opens SQLite.
connectOpens SqliteAlmacen, or returns the store you passed.
list_tasksStored assignments. tab may be Upcoming, Past due, Completed, or Grades.
list_filesStored files.
AlmacenThe contract. Subclass it and pass it to run(store=...).
SqliteAlmacenThe store that ships. It writes teams.db.
MemoryAlmacenThe same contract in memory, for a test that should not open SQLite.
TeamsScraperErrorA failure with a stable code and a message in the active language.

run

run(
    mode="upcoming",
    *,
    store=None,
    browser=None,
    subjects=None,
    parts=None,
    limit=0,
    no_detail=False,
    keep_open=False,
    chat="",
    download=None,
    interactive=False,
    language=None,
)
ArgumentWhat it does
modeupcoming, past-due, completed, activity, channels, chats, downloads, sync, open, or all.
storeAn Almacen. None opens SQLite and closes it at the end.
browserConfig id or executable path, for this call.
subjectsShortcuts or names. Required for channels and all when the config has no classes.
partsChannel parts. The default is posts and shared.
limitHow many assignments to open. 0 means all of them.
no_detailDo not open each card.
keep_openDo not close the window at the end.
chatAn allowed name, or all. Required for chats.
downloadNone follows the config. False skips downloads for this call.
interactiveFalse by default. If Teams asks for a sign-in, it raises auth.login_required. The terminal sets this when someone is at the keyboard, and then waits for Enter.
languageen or es for this call.

Data folder

run does not take the folder. connect(data_dir=...) sets it, or call teams_scraper.paths.set_data_dir first. TEAMS_SCRAPER_HOME does the same. Otherwise the folder is datos/ in the current directory.

run("upcoming", limit=1, store=my_store)

The contract for my_store is in Store. The SQLite tables are in Data.
