chats

Mensajes de las conversaciones que están en la lista permitida. Este comando no forma parte de all.

teams-scraper chats --chat "Study group"
teams-scraper chats --chat all

Hace falta --chat NOMBRE o --chat all. todos es lo mismo que all. Sin eso, o si el botón de Chat no aparece, el código es chats.missing.

Un nombre que no esté en chats de la config se detiene con chats.not_allowed. Añádelo con config. Lo que no está en la lista no se abre.

Qué lee

Abre la conversación, imprime los mensajes visibles y, si las descargas están activas, baja los archivos que se ven. No recorre un chat que hayas dejado fuera. Si el chat no se queda seleccionado, el código es teams.chat_unavailable. Si la lista no aparece, teams.chat_list_missing. Si no muestra ninguna conversación, teams.chat_list_empty.
