Almacén

El lector habla con un Almacen. No abre sqlite3 por su cuenta. SqliteAlmacen escribe teams.db. MemoryAlmacen es el mismo contrato en memoria.

from teams_scraper import Almacen, run

class JsonStore(Almacen):
    def __init__(self):
        self.tasks = []

    def save_task(self, task, tab, run_id=None, clear_reread=False):
        self.tasks.append(
            {
                "tab": tab,
                "id": task.get("id_en_html"),
                "title": task.get("titulo"),
            }
        )

store = JsonStore()
run("upcoming", limit=1, store=store)

Almacen ya implementa el resto de métodos como resultados vacíos. Sustituye los que quieras conservar. save_task es el que lanza si te lo saltas.

Una tarea necesita id_en_html o id_tarea. Sin id el código es storage.missing_id y no se escribe nada. Un campo vacío en una lectura posterior no sustituye un valor que ya está guardado. Un prefijo más corto de una frase guardada tampoco la sustituye.

Métodos

MétodoQué espera el lector
start_run(mode)Abre una corrida. Devuelve un id.
finish_run(run_id, result, processed, notes="")La cierra. result es completa, parcial o fallida.
save_task(task, tab, run_id=None, clear_reread=False)Guarda una tarea. tab es Upcoming, Past due, Completed o Grades.
task_needs_reread(task_id)Verdadero cuando Activity pidió leer otra vez esa tarjeta.
task_snapshot(task_id)La fecha y el estado guardados, o None.
list_tasks(tab=None)Tareas. tab filtra una lista.
list_files()Archivos ya guardados.
save_notifications(items, run_id=None)Filas de Activity. Devuelve cuántas eran nuevas.
apply_notification_actions(items, run_id=None)Marca tarjetas que Activity quiere volver a leer. Devuelve avisos de canal, relecturas y tareas nuevas sin detalle.
save_channel_posts(posts, run_id=None)Publicaciones de un canal.
save_channel_folder(record, run_id=None)Una carpeta compartida.
save_team_channel(record, run_id=None)El nombre de un canal.
save_channel_file(record, run_id=None)Un archivo compartido.
channel_file_downloaded(subject, channel, folder, name)El archivo guardado, o None.
save_grade(record, run_id=None)Una fila de notas.
sync_catalog()Copia catalogo/ a la base cuando esos archivos existen. Cada corrida lo llama antes de leer.
stats()Los conteos de la línea final: tareas, listas, archivos, avisos, carpetas y relecturas.
close()Suelta la conexión. connect() se puede usar con with.
