config

teams-scraper config cambia un campo de config.json. Los alias son configurar y editar.

El menú deja tocar una parte cada vez: idioma, clases, chats, navegador, carpeta, descargas, o volver a la config anterior. También puedes editar el JSON a mano.

Si el archivo no está, una lectura se detiene con config.missing. Si está roto, o no tiene browser, el código es config.invalid. Los dos te dicen que corras init.

Los nombres de abajo son los del ejemplo. No son una clase real.

{
  "language": "en",
  "browser": {
    "id": "chrome",
    "label": "Google Chrome",
    "engine": "chromium",
    "executable": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
    "profile": "perfil"
  },
  "subjects": [
    {
      "shortcut": "hist",
      "name": "History 101",
      "teacher": "A. Example"
    }
  ],
  "chats": ["Study group"],
  "download_files": true
}

Idioma

CampoPor defectoQué hace
languageenIdioma de los mensajes de esta herramienta. en o es. Teams puede usar otro idioma. --lang lo cambia para una sola corrida.

Navegador

CampoPor defectoQué hace
browser.idchrome, edge, brave, opera, firefox, librewolf, zen, o el nombre del ejecutable.
browser.labelNombre que sale en el encabezado.
browser.enginechromium o firefox. No hay un tercer motor.
browser.executableRuta completa del .exe. Si el archivo no está, browser.not_found.
browser.profileperfilCarpeta del perfil dentro de los datos. Se crea para esta herramienta.

Un LibreWolf que viva dentro de la carpeta de datos conserva librewolf/Profiles/Default si ese perfil ya está ahí. Si el perfil está abierto y el candado no se puede quitar, la corrida se detiene con browser.profile_locked.

Clases

CampoPor defectoQué hace
subjects[]Clases que la herramienta puede abrir en canales.
subjects[].shortcutNombre corto que pasas con -s. Por ejemplo hist.
subjects[].nameNombre de la clase tal como aparece en Teams.
subjects[].teachervacíoSe guarda junto a la clase. Si lo dejas vacío, la fila de la tarea usa desconocido.

Teams a veces cambia la ñ por un carácter roto. Si esa forma rota coincide con un docente guardado aquí, se queda el nombre guardado.

Chats y descargas

CampoPor defectoQué hace
chats[]Conversaciones que esta herramienta puede abrir.
download_filestrueGuarda archivos en descargas/. false guarda los nombres y se salta la descarga.

Carpeta de datos

La carpeta no es un campo del JSON. Es el sitio donde vive el JSON. Por defecto es datos/ en el directorio actual. --data DIR apunta una corrida a otra carpeta. TEAMS_SCRAPER_HOME hace lo mismo cuando lanzas la herramienta desde otro programa.
